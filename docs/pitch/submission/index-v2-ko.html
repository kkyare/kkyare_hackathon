작동 방식

필지 날씨 → 농장별 생산량 % → 실제 수확마다 재학습. 시즌이 쌓일수록 오차가 3.4 → 2.5 %p로 줄어듭니다(모델 없는 기준선 6.2). Claude가 농장을 찾고 브리핑을 쓰며, RL 과제에서 채점받는 에이전트입니다.
